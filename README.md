# Video Progress Tracker

This is a **Video Progress Tracker** web application designed to track a user's video viewing progress and save it in intervals. It consists of two main parts:

- **Frontend (React)**: The UI that allows users to watch videos and tracks their viewing progress.
- **Backend (Node.js with MongoDB)**: The server that stores the progress of users and videos in a MongoDB database.



## Features

- Tracks video progress in intervals
- Displays a progress bar based on the percentage of the video watched
- Saves progress so that users can resume from where they left off
- Uses MongoDB to store user progress data
- API to get and save progress


## Technologies Used

### Frontend:
- **React**: For building the user interface
- **Tailwind CSS**: For styling the frontend

### Backend:
- **Node.js**: JavaScript runtime for the backend
- **Express**: Web framework for building APIs
- **MongoDB**: NoSQL database to store user progress
- **Mongoose**: ODM for MongoDB
